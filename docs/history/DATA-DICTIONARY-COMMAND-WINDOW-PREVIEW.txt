Mean in a conditional profile
-----------------------------
Type: double table column

Meaning:
  Arithmetic mean of measured samples within each interval of a
  conditioning field. Example: intensity within a distance interval.

Request:
  opts = struct();
  opts.Edges = [-3 -1 1];
  opts.Statistics = {'Mean'};

  profile = farmConditionalStatistics(intensity, distance, opts);

Access:
  profile.Statistics.Mean

Interpret alongside:
  profile.Statistics.GroupID
  profile.Statistics.Bin
  profile.Statistics.LeftEdge
  profile.Statistics.RightEdge
  profile.Statistics.Count

Units:
  Mean retains intensity units.
  Interval edges retain distance units.

Requirements:
  Inputs contain corresponding samples. Select objects or spatial
  locations before calling. This operation rejects NaN and Inf.

Empty interval:
  Mean = NaN; Count = 0.

Identity:
  GroupID identifies supplied groups. Retain dataset/frame identity
  separately when calling this operation directly.

Example with known values:
  intensity = [10 20 30 40];
  distance = [-2 -1 0 1];
  profile = farmConditionalStatistics(intensity, distance, opts);
  profile.Statistics(:, {'LeftEdge', 'RightEdge', 'Count', 'Mean'})

Expected display (not a runtime verification):

    LeftEdge    RightEdge    Count    Mean
    ________    _________    _____    ____

       -3          -1          1       10
       -1           1          3       30

Intervals include their left edge and exclude their right edge,
except the final interval includes its right edge.
