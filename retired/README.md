# Retired code

This project-wide directory is reserved for historical functions and scripts
that have been replaced by validated FARM implementations.

Nothing is retired merely because a replacement has been drafted. A source may
move here after synthetic comparison against its replacement. The replacement
must remain prepared for later comparison with representative real data.

Each retired item must record:

- its original repository-relative path;
- the replacement function or workflow;
- the synthetic validation script and result;
- any behavior intentionally changed;
- the status of real-data confirmation.

No source files had been retired when this directory was created on 2026-10-10.
