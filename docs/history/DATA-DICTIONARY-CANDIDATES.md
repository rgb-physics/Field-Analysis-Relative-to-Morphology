# Data Dictionary candidate inventory

Scanned 2026-10-15. These are candidates for discussion, not approved schemas or promises of supported functionality.

Scan scope: **500 MATLAB source/workflow files and 2 Python source files** under APIs, Workflows, retired and scope-not-included. Test files and test runners are excluded. Archives and historical workflows are included but marked separately. No source datasets were opened.

Found **673 names with field/member/column evidence**, including **641 used in current API source or workflow examples**, plus **661 literal-only names requiring closer review.** Ten sampling diagnostic names have been added to the dictionary; the other candidates have not.

## How to read the inventory

- Field evidence includes named struct fields, table columns, member accesses, dynamic column suffixes, and Python dictionary/column/argument names. A member can be an input option, metadata, MATLAB-owned property or legacy field; this is not evidence that it is a public output.
- Literal-only review includes identifier strings such as requested measurements/statistics and option choices. Some are values, method names or filenames rather than fields and should be rejected or absorbed into another entry.
- Case-sensitive names remain distinct. Repeated names do not necessarily share semantics; definitions should identify their owning structure and producing/consuming functions.
- Dynamically composed names cannot all be enumerated statically. The explicit farmQueryField diagnostic suffix catalog is resolved; other user-selected names need naming templates such as <QueryName>_<Statistic> and <FieldName>_<ComponentName>_<Diagnostic> rather than individual entries for every prefix.
- Runtime custom fields, external Trackpy columns, mesh-library fields, and the complete MATLAB regionprops/regionprops3 property set need producer-specific checks. This scan is an inventory of code-visible names, not a proof of every possible runtime field.
- Full evidence, all source locations, domains and occurrence counts are in [the CSV](DATA-DICTIONARY-CANDIDATES.csv). The tables below give one source location per name; follow the CSV for every context.

## Suggested review groups

| Group | Examples / what to decide |
|---|---|
| Identity and time | DatasetID, Frame, ObjectID, ComponentID, DetectionID, TrajectoryID; distinguish frame numbers from stored time indices. |
| Sources and calibration | Data, Axes, SourceAxes, Size, Spacing, SpacingUnit, SourceGrid, Transform, Channels, TimeIndex; distinguish file descriptions from loaded images. |
| Segmentation | Mask, Masks, Labels, Channels, Thresholds, ChannelPrecedence, voxel/overlap/unclassified counts; preserve category order and provenance. |
| Memberships, geometry and supports | ObjectIDs, Components, PixelIdxList, Records, Indices, Grid, Type, Method, Status, Fallback; identify raw versus generated representations. |
| Shape measurements | Centroid, Volume, PhysicalVolume, PrincipalAxisLength, EigenVectors, Directors, ExtentInVoxels, ProjectedExtent, AspectRatios, ScaledDirectors, ScaledAspectRatios; record definitions, axes and units. |
| Reference and alignment | BoundaryDistance, DistanceGradient, RegionClass, ReferenceValid, ReferenceDirectionValid, Order, Order2D, Order3D, SignedAngle, SignedAngle2D, UnsignedAngle, Dot, Valid, Selected; distinguish generated references from sampled values. |
| Scalar sampling | Count, Mean, Sum, Std, Variance, Median, Min, Max, Quantiles, Histogram; prefixes, normalization and finite-value policies. |
| Vector sampling | ComponentMean, MeanVector, MagnitudeOfMean, MeanMagnitude, Covariance, CompleteVectorCount, IncompleteVectorCount, CovariancePairCounts; distinguish per-component, complete-vector and pairwise validity. |
| Sampling provenance | FieldGrid, SupportGrid, SourceGrids, MetadataDifferences, CorrespondenceVerified, FiniteSamplesOnly, EmptyGeometryCount, FallbackCount; counts/flags already begun. |
| Tracking | Detections, Links, Events, source/target IDs, overlap counts, inheritance choices, seed selections and background-seed status; separate ancestry from trajectory membership. |
| Field analysis | Power, FrequencyAxes, Radial, Normalization, Correlation, LagAxes, ZeroLagIndex, Edges, Statistics, ExcludedCounts; record units, bin conventions and applied factors. |
| Mesh and visualization | Vertices/faces, mesh-associated fields, plotted quantities, export/view settings; assess separately because SurfaceFieldMapping has not been reworked. |
| Workflow outputs | Measurements, Diagnostics, Filaments, Files, Directory, Seconds, ReferenceInfo, HeavyMasks; distinguish example-specific containers from shared API contracts. |
| Historical names | Lengths, AniLengths and other legacy conventions; document migration/aliases only after verifying producers and consumers. |
