# AI workflow handoff workshop

## Purpose

Develop a handoff that users can give to their own AI to turn an analysis goal
into a tractable, readable MATLAB workflow using FARM's package capabilities and
workflow standards. This complements the runnable examples for different levels
of coding comfort.

Work through one step at a time. Record agreed decisions separately from proposals
before drafting the next part. The initial proposal is not an approved design.

## Workshop files

- [Proposal](PROPOSAL.md): starting concept and boundaries to discuss.
- [Workshop steps](WORKSHOP-STEPS.md): discussion order and completion criteria.
- [Decision log](DECISIONS.md): confirmed decisions and open questions.
- [User-to-AI handoff draft](USER-AI-HANDOFF-DRAFT.md): first draft for role-play and review.
- [Code conventions](FARM-CODE-CONVENTIONS-DRAFT.md): package writing-style reference, retained as a review draft and supplied beside the handoff.

## Current step

Review the first handoff draft, then role-play its access check and opening interview.
The original workshop sequence remains a planning aid; the user's scope corrections
are recorded in the decision log.
